# Sleeve Notes for the Frog Trio

One album title and a back-cover blurb for a jazz trio made entirely of frogs.
Running `main.py` validates the entry and writes it to `/output/entry.txt` as
UTF-8 text. The program uses only the Python standard library.

```sh
python3 main.py
```

Pass `--output PATH` to write somewhere else. No prizes are claimed here.
